# 爱给网 (Aigei) 音频批量下载指南

本目录包含针对爱给网试听音频（MP3 / MIDI）的完整批量提取与下载方案。

---

## 🔍 原理分析与“还需要什么”说明

经过对你的 `报文.txt`（HAR 网络记录）以及 `页面.html` 的底层逆向分析：
1. **播放请求机制**：
   - 点击播放按钮（`audio-player-btn`）时，网页会向 `https://www.aigei.com/f/d` 发送一个 `POST` 请求。
   - 请求体中的 `v` 参数和请求头 `x-requested-etag` 是由前端 JavaScript 加密算法（混淆函数 `cupie`, `dfu`, `ssssdddttssssStr`）动态生成的。
   - 服务器在响应中返回经过 Base64/特定算法加密的真实直链（七牛云 CDN 存储地址，如 `https://s5.aigei.com/src/aud/mp3/...mp3?token=...`），前端解密后进行播放。
2. **为什么外部纯 Python 无法直接裸发请求？**
   - **核心关键：服务端校验了浏览器 Cookie！**
   - 经过实测，如果在没有 Cookie 的情况下直接向 `/f/d` 模拟 POST，服务端会直接拦截并返回：
     > `{"errorCode":"forbidden","message":"很抱歉,系统出错...造成此原因：禁止该网站使用 cookie...请允许本网站使用 cookie..."}`
3. **还需要什么？**
   - **如果用纯脚本外部请求**：还需要你的**浏览器当前有效 Cookie**（或当前登录态），且需要维护前端容易变更的混淆加密算法。
   - **如果使用方案一（控制台一键脚本，强烈推荐）**：**什么都不需要额外提供！** 浏览器原生自带 Cookie、会话状态以及官方所有加解密函数，一键运行 100% 成功。

## 🚀 两种使用方式

### 方案一：浏览器控制台一键全自动下载（⭐ 强烈推荐，最简单免配置）

只要你在浏览器（Chrome / Edge 等）里打开了爱给网页面：

1. 打开爱给网歌曲列表页面（例如：`https://www.aigei.com/music/midi/` 或本地网页）。
2. 按键盘 **`F12`**（或右键 -> 检查），切换到 **`Console`（控制台）** 标签页。
3. 打开本地文件 [browser_downloader.js](file:///e:/work/skymusic/downmidi/browser_downloader.js)，**全选复制全部代码**，粘贴到控制台并按 **回车（Enter）**。
4. 页面右下角会立即弹出一个精致半透明的控制面板：
   - 自动识别页面上所有 75 首歌曲。
   - 点击 **【🚀 开始提取并下载】**：脚本会自动静音遍历每一首歌曲，逐个获取真实播放直链并自动下载到浏览器的下载文件夹中（文件自动命名为 `01. 花之舞.mp3` 或 `.mid`）。
   - 点击 **【📋 仅提取并导出】**：只抓取所有直链，抓完自动生成并导出 `aigei_download_links.txt` 和 `aigei_songs_metadata.json`，可配合迅雷、IDM 或下方的 Python 脚本超多线程并发秒下载！

> **内置安全策略**：脚本自带 1.2 秒请求延时，避免触发爱给网的高频爬虫反爬风控；自带静音保护，提取时不会发出刺耳重叠播放杂音。

---

### 方案二：Python 多线程极速下载（配合导出的下载列表）

如果你通过方案一导出了 `aigei_download_links.txt`（或者自己收集了直链）：

1. 将导出的 `.txt` 文件复制到 `downmidi/` 目录下（或者改名为 `links.txt`）。
2. 在终端运行：
   ```bash
   python download_music.py
   ```
   或指定文件：
   ```bash
   python download_music.py --links links.txt --workers 8
   ```
3. 脚本会自动启用多线程并发下载，展示彩色进度条，自动识别音频格式（`.mp3` 或 `.mid`），并保存在 `downmidi/downloads/` 目录中。

### 方案三：Playwright 全自动模式（推荐工具：auto_downloader.py）

我们为你编写了专用的全自动驱动工具 [auto_downloader.py](file:///e:/work/skymusic/downmidi/auto_downloader.py)：

1. **首次运行（窗口模式，完成一次登录）**：
   ```bash
   python auto_downloader.py --gui
   ```
   - 脚本会自动弹出一个 Chromium 浏览器窗口打开爱给网页面；
   - 因为爱给网检测到新浏览器会强制弹出【请登录后进行访问】弹窗，你只需在弹出的窗口中扫码或点击登录（只需登录这一次，后续凭证会自动持久化保存到本地 `.browser_session/`）；
   - 登录完成后，脚本会**立即全自动接管**：自动逐首调用试听接口、捕获真实直链并下载到 `downloads/` 目录中！

2. **后续运行（完全无头后台全自动运行）**：
   ```bash
   python auto_downloader.py --headless
   ```
   - 凭证已自动保存，无需弹出任何窗口，全自动在后台静默抓取并下载整页所有音频！
